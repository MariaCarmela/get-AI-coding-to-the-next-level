# Debug Exercise

## Context and Material

You are given a minimal AI-powered enrichment pipeline:
Fetches users from a public API
Enriches them with AI-generated summaries (simulated LLM call)
Stores results in a local JSON database
Uses asyncio and aiohttp
The system is broken due to 5 non-trivial bugs spanning: async design, blocking calls,
concurrency safety, data integrity, API schema logic.
You are given a project with this structure:

```
main.py
ai_client.py
storage.py
requirements.txt
```
You must:
Run the system and identify the 5 bugs
Fix them
Refactor only where strictly necessary
Ensure:
correct async execution
no blocking calls
correct API field usage
safe data storage
deterministic behavior


```
Deliver
```
#### Submission package:

```
main.py
ai_client.py
storage.py
db.json (generated by running the fixed pipeline locally)
bug_report.md with:
bug description
type (async / data / logic / concurrency / architecture)
effect
fix you made
```
## Task

You will debug and fix an asynchronous AI data pipeline that fetches user data from an
external API, enriches them through an AI simulation layer, and store them into a local
database. The exercise focuses on async correctness, data integrity, concurrency safety,
and AI-assisted debugging workflows.

### How to start the project

```
Make sure you have a virtual environment to run the project in:
python -m venv venv
Activate the venv
<venv-directory>/venv/Scripts/activate
Install the requirements from project directory
pip install -r requirements.txt
Start the project
python main.py
Debug!
```
