# AI-Assisted Test Generation Exercise

This is a minimal exercise to practice using AI tools for unit test generation. You will write pytest tests (with AI help) for a function, run coverage, and submit the coverage report.

## 1. Set up the environment

From the project root (`my_exercise/`):

```bash
# Optional but recommended: create and activate a virtual environment
python -m venv .venv
# On Windows:
.venv\Scripts\activate
# On macOS/Linux:
# source .venv/bin/activate

# Install dependencies
pip install -r requirements.txt
```


## 2. Code organization

The main business logic is split across these files:

- `calculator.py`: main `calculate_price` function (public API)
- `validation.py`: input validation helpers
- `coupons.py`: coupon logic
- `time_rules.py`: time-based rules
- `exceptions.py`: shared exception and constants

You should import the main function as:

```python
from calculator import calculate_price
```


## 3. Write tests using AI

- Review the code in `calculator.py` and related modules.
- Ask your AI assistant to propose a set of **pytest** unit tests that cover as many branches and edge cases as possible (validation, coupons, user status, time-based discounts, etc).
- Place your test files alongside the source files (e.g. `test_calculator.py`) — an example has been provided for reference.
- You can split tests into multiple files (e.g. `test_validation.py`, `test_coupons.py`, etc.) if you wish.
- You can refine the tests (rename them, add missing edge cases, fix imports) as needed.


## 4. Run the tests with coverage

From the project root:

```bash
coverage run -m pytest
coverage report -m
```

You will see a coverage report in the terminal. Optionally, for an HTML report:

```bash
coverage html
```

This creates an **`htmlcov/`** folder; open `htmlcov/index.html` in a browser.

## 5. Submission

Create a zip file containing exactly these files:

```
test_calculator.py
test_validation.py    (optional — you can split tests across multiple files)
test_coupons.py       (optional)
test_time_rules.py    (optional)
coverage.json
```

**Required files:**

- **`test_*.py`** — one or more test files. Each file must be named with the `test_` prefix (e.g. `test_calculator.py`, `test_validation.py`). You can use a single file or split tests across multiple files.
- **`coverage.json`** — the JSON coverage report generated by running:
  ```bash
  coverage run -m pytest
  coverage json
  ```
  This produces a `coverage.json` file in the project root.

**Do not include** `htmlcov/`, `.coverage`, or any other files — only `test_*.py` files and `coverage.json`.

Good luck!
